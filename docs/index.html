Spec values

Overview

Each spec scored 0–100 among the selected phones (100 = best for that spec, 0 = worst). Grey = no data.

Per spec

By default each chart is sorted by its own values (price from cheap to expensive, chipset from slow to fast…). Pick a spec in Sort phones by to use the same phone order in every chart. The base is orange; hover over a point or bar to see its value. Choose specs in the Specs tab.

Per phone

Left: advantage over the base for each spec (green = better). Right: 0–100 scores of the phone (blue) against the base (orange).

Phones

Untick phones to take them out of every table and chart (handy when the list grows, or when you are down to a few finalists). Click a row to toggle it. Use Edit to correct a phone's specs.

Which specs to take into account

Untick specs you don't care about: they disappear from the comparison, the charts, the 0–100 scores and the "best phone" table.

Add a phone

To add or edit phones from here, open the report in app mode: double-click run_app.bat (or run phone-compare --serve). This file is a static copy and can't change your CSV files.
You can still fill in the form and press Copy CSV row to paste the line into data/phones.csv yourself.

Built mostly by Claude (an AI by Anthropic). The idea, requirements and feedback came from the project owner; Claude wrote most of the code. Phone prices and specs were collected from shop listings and benchmark sites and may be out of date or wrong: check them before buying.

Want to use it with your own phones? Download the project and edit the CSV files offline. Ideas for a JavaScript-only version or hosting it on a server: contact arnaucnadal@disroot.org.
